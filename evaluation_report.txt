============================================================
KNOWN LIMITATIONS OF THE CURRENT ARCHITECTURE
============================================================
- Only the first 50 articles are indexed, so questions about
  topics outside this subset cannot be answered.
- The grounding check is word-overlap based, not semantic, so a
  correct paraphrase can score low and copied text can score high.
- The database is rebuilt in memory on every startup; there is no
  persistent vector store, which does not scale.
- Chunking is fixed-size (700 chars) and can split sentences
  mid-idea; semantic chunking would preserve meaning better.
- The free LLM tier is rate-limited and occasionally returns
  low-quality or off-format responses.
- Generation dominates latency (a network call); retrieval itself
  takes only milliseconds.
- NER labels from the general-purpose spaCy model are imperfect on
  technical text (e.g. 'Earthsystem' tagged as PERSON).
